Network and telemetry:
- The only HTTP client in macos_apps_mcp/ is `httpx.AsyncClient` in daemon.py L218, which

  `urllib.parse` only.
- The daemon dashboard binds `127.0.0.1:47632` (daemon.py L40-42), loopback only.
- No telemetry code exists. `opentelemetry-api` is in uv.lock only as a FastMCP dependency;
  no SDK or exporter is installed, so it emits nothing. Per-tool usage counts stay in a local
  file (audit.py L160, `usage.jsonl`). Do not mention OpenTelemetry in the README.
- Sending mail and opening URLs happen through Mail and Safari, only when the matching tool
  is called (send tools only when enabled).

Tiers:
- `MACOS_APPS_READ_ONLY=1` (or `true` / `yes`) registers reads only (tiers.py).
- Send tools are absent unless enabled per app: `macos-apps-mcp allow-send mail`
  (`mail` / `messages` / `all` / `off`; deploy.py L470) persists the choice for the daemon;
  `MACOS_APPS_ALLOW_SEND=mail` is the stdio form. READ_ONLY wins over both.

Audit and Mail recovery:
- Audit log: `~/.local/state/macos-apps-mcp/audit.jsonl`, or
  `$XDG_STATE_HOME/macos-apps-mcp/audit.jsonl` when that variable is set (audit.py L49-58);
  rotates past ~5 MB with one backup (audit.py L46).
- Every destructive Mail write goes through adapters/mail_recover.py: it copies each
  message's RFC822 bytes to a `.eml` file under
  `~/.local/state/macos-apps-mcp/backup/mail/<receipt-id>/` (L317-320), logs the plan, then
  acts (L1-40). `mail_undo` with the receipt reverses the batch (dry_run default true).
- `trash_mail` moves to Trash; no tool empties the Trash (docs/mail-applescript-facts.md §5c;
  README tail already says so under "Cleaning up duplicate mail").

Known limits to state honestly (link docs/mail-applescript-facts.md):
- A message Mail downloaded only in part (`.partial.emlx`) is backed up WITHOUT its
  attachments (mail_recover.py L21-32; facts §4c).
- A move out of a Gmail label can read `ok`, then the copy is back about 2 minutes later
  (facts §2, #291).
- A send result `sent: True` means Mail accepted the message, not that it was delivered
  (README "Outbound (send) mode").

Permissions:
- EventKit: Calendar + Reminders.
- Automation, one dialog per app: Mail, Notes, Contacts, Safari, Messages, Music
  (doctor.py `_AUTOMATION_APPS` L39-46). Shortcuts uses the `shortcuts` CLI.
- Full Disk Access is optional. Tools that declare it (server.py `permission=`): Messages
  content (`messages_search`, `messages_with`, `message_body`; `messages_chats` needs none),
  all Photos tools, Mail's index reads (`mail_search`, `mail_thread`, `mail_overview`,
  `mail_stats`, `mail_bodies`, `export_mail`, `mail_duplicates`), and `reminders` (tags and
  subtasks). Notes uses it for the fast path. Without it, Notes and some Mail reads fall back
  to a slower Automation path, and the rest return an error or a `coverage` note that names
  the grant.
- Under stdio, macOS gives each grant to the app that launched the server (Claude Desktop,
  Terminal, VS Code), so each client needs its own grants. The signed `.app` daemon holds one
  grant set for every client (docs/DAEMON.md).
- Adapter names for `MACOS_APPS_ADAPTERS_OFF`: calendar, contacts, mail, messages, music,
  notes, photos, reminders, safari, shortcuts. Under the daemon the list lives in
  `~/.local/state/macos-apps-mcp/adapters_off` and needs a restart. Anchor already in use:
  docs/DAEMON.md#6-turn-adapters-off-under-the-daemon.
