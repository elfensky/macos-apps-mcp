<objective>
FIX-07 (#373): the `.app` installs the bundled `macos_apps_mcp` package from a wheel
built in a hash-pinned build environment.

- A `build` dependency group (`["hatchling"]`) puts the backend and its dependencies in
  `uv.lock` with hashes; it is not a default group, so `uv sync` never installs it.
- `scripts/build_app.sh` exports that group, builds the wheel with
  `uv build --wheel --build-constraints … --require-hashes`, and installs the wheel with
  `--no-deps`. The D-16 export guard and the runtime installs do not change.
- Two text tests fail if the backend becomes unpinned; two negative probes and one
  unsigned build prove the script.

Purpose: the build backend that writes the bundled package meets the same hash discipline
as every runtime dependency.
Output: one PR rebase-merged to `develop` (`Closes #373`).
</objective>

under `--require-hashes`, then installed. `--require-hashes` belongs on `uv build`, never
on the wheel install (Pitfall 2).

and the PR body.
