# Phase 04.1 Plan 02: typed refusals for an existing file and a failed mkdir Summary

**files refusals are typed WriteRefused — PR #392 (https://github.com/elfensky/macos-apps-mcp/pull/392), closes #383**

`files.target_path` and `files.publish` now raise `WriteRefused` (kind `write_refused`) with the unchanged "never overwrites" text. `files.resolve_dest` turns any OSError from its `mkdir` into a `WriteRefused` that names the resolved path, the OS reason, "nothing was written" and "Do not retry". The three file-writing tools now give the agent the bare directive, not `Error calling tool ...` with a traceback in the log. `server._guard` is untouched.
