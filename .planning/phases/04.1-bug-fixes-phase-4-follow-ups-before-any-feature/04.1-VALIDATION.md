## Sampling Rate

- **After every task commit:** Run the quick run command (in the plan's lane, `.worktrees/<slug>`)
- **After every plan wave:** Run the full suite command; each wave is one plan and lands by its own PR, so the full suite runs before every push
- **Before `/gsd-verify-work`:** Full suite must be green on `develop`, and the 04.1-04 unsigned build log must hold `universal2 gate ok`, both `smokes ok` lines and `built:`
- **Max feedback latency:** 60 seconds (the unsigned `.app` build in 04.1-04 Task 2 is a one-time proof, run in the background, outside this loop)
