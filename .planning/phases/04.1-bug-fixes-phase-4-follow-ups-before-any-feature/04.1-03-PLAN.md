<objective>
FIX-10 (#387): a killed `export_photo` leaves no hidden copy that a later call keeps, and
a cleanup error never replaces the outcome.

- The staging prefix carries the pid: `.macos-apps-mcp-export-<pid>-`.
- On entry, `files.staging()` removes only staging directories in the same parent whose
  pid is dead — exact name, real directory, owned by this user, mode 0700, never this
  process's own, never a live one.
- The `finally` cleanup logs an OSError as a warning that names the leftover directory;
  the body's result, or its typed error, stands.

Purpose: a private photo copy does not stay hidden in the user's Downloads for good, and
a written photo is never reported as an untyped failure.
Output: one PR rebase-merged to `develop` (`Closes #387`).
</objective>
