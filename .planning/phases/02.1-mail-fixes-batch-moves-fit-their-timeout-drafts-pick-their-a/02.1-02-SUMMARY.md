# Phase 02.1 Plan 02: Unowned Sender Refusal and create_draft's from_address Summary

MAIL-03/04 code landed: create_draft picks its sender, unowned senders refused; #230 cap 120s — PR #247.

Mail does not reject a `from_address` no account owns — it silently sends from its default
account instead (spike 005, device-verified). `mail_addressing.owned_addresses()` is a new
fail-closed read of every account's addresses; `mail_outgoing.owned_sender()` checks a caller's
`from_address` against it and raises before any native write, wired into `send_mail`'s dispatch
closure so the check can never run on a dry run. `create_draft` gains the same `from_address`
parameter, applied the identical way, at all four layers the plan named. `quoted_body`'s read of
a reply's original now carries a 120s cap (#230), matching the script's own backstop.

## Accomplishments

- `mail_addressing._MY_ADDRESSES` moved verbatim from `mail_triage.py` (same object,
  `mail_triage` now imports it by name); `mail_addressing.owned_addresses()` reads it and fails
  CLOSED — an unreadable Mail propagates its typed error, and an empty result raises
  `NativeError` rather than being read as "nothing is owned."
- `mail_outgoing.owned_sender()` extracts the address inside the last `<...>` (never
  `email.utils.parseaddr`, which mis-parses Mail's own `x@y <X@Y>` shape), matches
  case-insensitively against `owned_addresses()`, and returns Mail's own spelling or raises
  `ValueError` naming the refused address and the owned ones.
- `new_message()`'s `dispatch()` closure resolves the spelling as its first statement, before
  `body_file`/`_SEND` — `deliver()` only calls `dispatch()` when `dry_run=False`, so the dry run
  makes no native call and its preview still reports the caller's typed value.
- `create_draft` carries `from_address` through the tool, `MailAdapter`, `mail_drafts.create_draft`
  and `_CREATE_DRAFT`'s new 4th argv item (`if fromAddr is not "" then set sender of msg to
  fromAddr`, mirroring `_SEND`'s own line verbatim, placed after the body is set and before the
  recipient is added). The locator gains `from`.
- Both tool docstrings (`create_draft`, `send_mail`) state the refusal contract; `create_draft`'s
  also routes replies to `mail_reply`.
- `quoted_body`'s `_ORIGINAL` call gains `timeout=120.0` (#230), equal to the script's own 120s
  backstop (GATE-10's `>=` invariant passes on equality).
- `mail_reply`, `reply_all` and their builders received no code change (D-12).
