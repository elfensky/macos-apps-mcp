# Phase 05.1 Plan 05: Mailbox labels Summary

FIX-11 of #427. `mail_addressing.cached_account_names()` returns a copy of the Mail adapter's
in-memory account map and never runs osascript. `mail_addressing.mailbox_label(url)` turns
`imap://UUID-1/%5BGmail%5D/Trash` into `Personal › [Gmail]/Trash`. A `local://` url reads
`On My Mac › <folder>`. A canonical name, a non-str, an unknown account, an empty uuid and a
cold cache come back unchanged, so the page shows the raw value.

The seven sites of RESEARCH D1.4 use the label: the batch title (normal and `mail_undo`
forms), the recovery `from` sources and `to` destination, each target row's `from` line, the
undone banner, the Backups receipt row, and the search haystack (the label beside the raw
value). `writes._raw` keeps the raw `imap://` lines. Every label goes through `h()`; none is
wrapped in `Safe`. `mailbox_url.py` is untouched.
