## Pattern Assignments

### `adapters/mail_addressing.py` (utility, transform) - #427

**Analog:** cache block `mail_addressing.py:240-255` and `mailbox_url.parse` (`mailbox_url.py:88-96`).

Cache is process-local, "NO at-rest source". The accessor reads the global only:
```python
_ACCOUNT_MAP_CACHE: dict[str, str] | None = None   # :246
```
`parse` returns `(scheme, uuid, DECODED path)` or `None` without `://`. Use it as the only parser.
Code to add is in RESEARCH D1.2 (`cached_account_names`, `mailbox_label`). `ON_MY_MAC` is at :432.
Never call `account_map()` (it launches Mail via osascript).

### Render sites (utility/component, request-response) - #427

Pattern: wrap the raw value in `mailbox_label(...)` before it enters `h()`. Keep `h()` escaping.
Never wrap a label in `Safe`. Keep the `str(...)` coercions.

`recovery.py:134-136` (site 1):
```python
folder = (
    h('<div class="faint">from {}</div>', t["folder"]) if t.get("folder") else ""
)
```
becomes `mailbox_label(str(t["folder"]))` as the `h()` argument.

`writes.py:229-238` (site 4): compute `dest = mailbox_label(dest)` once, before both title forms
(normal and `mail_undo`).

`backups.py:72-77` (site 6): `title += f" → {mailbox_label(dest)}"`.

Leave `writes._raw` (:405) raw. Add the label to `_haystack` (:695) and keep the raw value too.
Import `from ..adapters import mail_addressing` the way `recovery.py:22` and `backups.py:19`
import `mail_recover`.

## Shared Patterns

### Escape everything (D-09)
**Source:** `macos_apps_mcp/dashboard/html.py` `h()`, `join()`, `Safe`.
**Apply to:** every changed render site, banner notice, mailbox label and skip link.
Only literal markup is `Safe`. Never wrap data or a label.

### Audit never raises
**Source:** `audit.audit_write` (:61-72), `except Exception as e:  # noqa: BLE001`.
**Apply to:** WR-06. Return a bool and keep the swallow.

### Late-bound resilience (a dashboard fault must not take MCP down)
**Source:** `daemon.serve()` :319-325.
**Apply to:** WR-05 (build failure) and IN-04 (unusable key).

### Test isolation
**Source:** `tests/conftest.py` `_isolated_state` (session), `_reset_account_map_globals` (autouse, :56-77).
**Apply to:** all new tests. The autouse `_no_real_osascript` fails any osascript call, so it
proves the cache-only accessor. If a new global joins the account-map cache, reset it in
`_reset_account_map_globals`.

### Import and style
`from __future__ import annotations`; ruff E,F,I,UP,B,SIM, line length 88. Mail modules use
qualified `from .. import runtime`. Dashboard modules reach shared helpers by public names
(IN-03). Gate: `uv run pytest && uv run ruff check . && uv run ruff format --check .`.
