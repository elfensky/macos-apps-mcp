# Phase 05.1 Plan 01: Daemon start hygiene Summary

`daemon.serve()` now wraps the late dashboard import, the key read and `build_app` in
one `try/except Exception`. On a fault it logs `dashboard not built: …` with the
traceback, sets `dashboard_state = "not built: <text cut to 120>"` (an empty message
names the exception type), closes the TCP socket and serves MCP over the unix socket
alone. The state holds `http://127.0.0.1:<port>` only after a successful build with a
usable page key; an unusable key gives `key unusable: every page answers 503; remove the
dashboard_key file and restart the daemon`.
