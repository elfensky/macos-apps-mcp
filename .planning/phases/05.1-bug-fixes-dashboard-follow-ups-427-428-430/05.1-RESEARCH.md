### D1.2 Reading it with no native call and no cross-adapter import
`dashboard/` is not an adapter; `recovery.py:22` and `backups.py:19` already import `mail_recover`. Add two functions to `mail_addressing.py` (no new module):

```python
def cached_account_names() -> dict[str, str]:
    """uuid -> name from the cache ONLY. Never osascript: a page must not launch Mail (#427)."""
    return dict(_ACCOUNT_MAP_CACHE or {})

def mailbox_label(url: str) -> str:
    """'Personal › INBOX' when the account is cached; 'On My Mac › …' for local://;
    the value unchanged when it is not a url or the account is unknown."""
    parsed = mailbox_url.parse(url) if isinstance(url, str) else None
    if not parsed:
        return url
    scheme, uuid, path = parsed
    name = ON_MY_MAC if scheme.lower() == "local" else cached_account_names().get(uuid)
    if not name:
        return url
    return f"{name} › {path}" if path else name
```

`mailbox_url.parse` returns `(scheme, uuid, DECODED path)` and `None` without `://` (`mailbox_url.py:88-96`), so canonical names (`INBOX`, `Trash`, as in the test fixtures) pass through. `mailbox_url.py` stays pure ("stdlib only, no sibling-adapter imports"; it cannot import `ON_MY_MAC`), hence the label lives in `mail_addressing`.

Display form: `<account name> › <decoded path>`, `/` kept inside the path (`Personal › [Gmail]/Trash`); `mailbox_url.leaf()` docstring warns a leaf "is a display name, never an address". Fallback: the raw URL, escaped. Two accounts with one name give identical labels (accepted; raw lines remain).

## Common Pitfalls

1. Calling `account_map()` from a page launches Mail; the autouse `_no_real_osascript` guard turns the slip into a failing test.
2. Labelling `_raw`: it is the evidence, keep it raw.
3. Patching only two TCC constants: `doctor._FDA_PATHS` is a frozen copy.
4. Setting `dashboard_state` before the build, or leaving the TCP socket open after a failed build.
5. Unbounded exception text in `dashboard_state` breaks the `doctor` budget test.
6. `aria-pressed` -> `role="switch"` leaves old CSS selectors and 4 old assertions.
7. Framing Guard refusals: `guard.py:79-104` runs before the key check; a framed page would read the audit log for sidebar counts for an unauthenticated caller. Only in-app 409/400 get the frame.
8. Padding a switch for 44px grows the visible switch; use the transparent `::after`.
9. An opacity dim cannot reach 4.5:1 for muted text; change the mechanism.
