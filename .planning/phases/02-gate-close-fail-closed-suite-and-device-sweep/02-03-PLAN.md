<objective>
Per D-04, make the Mail write tests run on 2 marker mails only, never on real mail.

Today `inbox_messages` (`tests/test_integration.py:1524`) takes the first 2 messages of whichever
INBOX `overview()` lists first. Those are real mails, and the account can differ from the one
`scratch_mailbox` picks (RESEARCH Pitfall 2). This plan rewrites the fixture to select by a fixed
marker subject, in the scratch account's INBOX, and to fail loud with the seed command when fewer than
2 are there. It touches tests only; the one-time seed runs on device in plan 02-04.

Marker details (CONTEXT discretion): subject `macos-apps-mcp sweep marker`; the seed command sends 2
mails to `andrei@lav.ren` through `MailAdapter().send(..., dry_run=False)`, the same path
`test_send_to_self_and_delete_draft_round_trip` uses; the account is the one `scratch_mailbox`
already picks (non-Gmail first; 01-08 used `Personal/macos-apps-mcp-test`).

Output: one test-only PR rebase-merged to develop.
</objective>
