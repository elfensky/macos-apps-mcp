## External Research

- FastMCP 3.4.7 proxy: the daemon sees the proxy Client's `mcp 0.1.0` and a new session per
  call; a `client_factory` on `FastMCPProxy` runs inside the shim's request context and can copy
  `get_context().session.client_params.clientInfo`; traps at `initialize` (`client_params` None)
  and `ping_remote` (no context). Verified with an in-memory probe.
  (Source: `fastmcp/server/providers/proxy.py:90,180,632,814-858,921`; `mcp/client/session.py:19`)
- AppleScript `repeat with p in (… whose …)`: the loop variable is a reference to `item k of` the
  specifier, so each property read can re-run the scan; `get` or one bulk event per property
  avoids it. (Source: https://developer.apple.com/library/archive/documentation/AppleScript/Conceptual/AppleScriptLangGuide/reference/ASLR_control_statements.html;
  https://www.macscripter.net/t/a-reference-to-trick-no-longer-applies-for-leopard/50661;
  https://forum.latenightsw.com/t/how-do-i-search-contacts-for-string-in-email-address/676/16)
- `gh release download` sets no quarantine xattr (tested with gh 2.102.0); AirDrop does.
  (Source: https://eclecticlight.co/2025/12/08/who-decides-to-quarantine-files/)
- Mail: disabled accounts probably stay in `every account` (sdef `enabled` property); a removed
  account's rows stay in the Envelope Index. (Source: https://github.com/iret77/apple-mail-mcp/issues/25;
  https://support.apple.com/en-lk/guide/mail/if-an-email-account-is-inactive-mlhlp1207/15.0/mac/13.0)
- NoteStore: `ICNote.noteData` is non-optional in the macOS 27 model, so a live note has
  `ZNOTEDATA`; the iMac's macOS 15 model was not inspected.
  (Source: `NotesShared.framework/…/NoteData.mom` read with `NSManagedObjectModel`)
- AddressBook: `ZABCDRECORD` with `ZFIRSTNAME`/`ZLASTNAME`/`ZORGANIZATION`, one store per
  source; entity name to confirm in `Z_PRIMARYKEY`. (Source: https://github.com/jasonpaulso/apple-mcp-pro `utils/contacts.ts`)
