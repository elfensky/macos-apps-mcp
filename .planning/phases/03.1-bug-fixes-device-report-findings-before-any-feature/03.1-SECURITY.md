## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| iMac session / SSH → the owner's Contacts, Notes and Mail stores | the probe and the proofs read real stores and call real apps through the daemon | counts, seconds and booleans only |
| iMac reply → records lane → public repo and issue comments | anything measured can reach a SUMMARY, a JSON record or an issue | privacy-grepped text; no name, title, subject, address or UUID |
| MCP client → shim → daemon → audit log | `clientInfo` and `dry_run` arrive from an untrusted client | advisory labels, bounded; `dry_run` coerced as the tool coerces it |
| this Mac's build → scp → the iMac's `/Applications` and launchd | a bundle crosses the LAN and runs with the iMac's grants | signed, sha256-matched, stamped bundle |
| AppleScript query → Contacts | a user-typed query reaches an AppleScript | argv item, never interpolated |
