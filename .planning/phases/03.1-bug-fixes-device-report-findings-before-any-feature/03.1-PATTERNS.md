## Pattern Assignments

### `registry.py` - `dry_run_defaults()`
**Analog:** `audit_verbs()` (121-129). Copy its shape.
```python
def audit_verbs() -> dict[str, str]:
    return {
        n: r.audit_verb
        for n, r in TOOLS.items()
        if r.audit_verb is not None and r.registered
    }
```
Difference: do NOT filter on `r.registered`. CI runs the suite a second time with `MACOS_APPS_READ_ONLY=1`, and send tools are unregistered by default. Use all `TOOLS` records. Derive the default with `inspect.signature(rec.fn).parameters.get("dry_run")`, as `tests/test_registry.py:363` does. Return `None` (skip) when the parameter is absent or has no default.

### `audit.py` - envelope keys `dry_run`, `caller`, `session`
**Analog:** `AuditMiddleware.__init__` and `on_call_tool` (230-272). Add a third ctor argument `dry_run_defaults: Mapping[str, bool]` beside `audit_verbs`. Existing tests call `AuditMiddleware(audit_verbs=..., snapshot_sources=...)`, so give the new argument a default of `{}`.
```python
args = dict(context.message.arguments or {})      # keep as sent; never write dry_run into args
...
audit_write({"ts": ..., "tool": tool, "op": self._audit_verbs[tool],
             "args": _audit_args(args), "target_id": ..., "before": before, "after": after})
```
Add `"dry_run": <bool>` and `"caller": <str>` to that dict, and `"session"` only when present. Resolve both BEFORE `call_next`. Coerce with `TypeAdapter(bool).validate_python` (pydantic is a transitive dep of `mcp`; do not edit `pyproject.toml`, because `version.yml` fails any PR that touches it). On `ValidationError` fall back to the default. Read the caller from `getattr(context, "fastmcp_context", None)` and catch `AttributeError` and `RuntimeError`, because test contexts are `SimpleNamespace` without that attribute. Bound labels with `text.clean_summary`. Keep the existing `except Exception: pass` around `audit_write`. Readers keep using `.get()`.

### `daemon.py` - `run_shim` client factory
**Analog:** current `run_shim` (236-250) plus `_uds_client_factory` (kept untouched, `Timeout(None, connect=10.0)` and the #302 handler live there).
```python
proxy = create_proxy(_Client(_HttpTransport("http://daemon/mcp",
        httpx_client_factory=_uds_client_factory(path))))
proxy.run()  # stdio transport
```
Replace with `FastMCPProxy(client_factory=_shim_client_factory(transport, shim_id)).run()`. Extract the factory as a module-level function so a unit test can drive it. Inside `f()`, read `get_context().session.client_params.clientInfo`. Fall back to a fixed shim identity when `client_params` is `None` (the `initialize` path) or when `get_context()` raises (the `ping` path). Add the shim id as an extra `Implementation` field. Remove the now-unused `create_proxy` import (ruff F401). Keep the order `socket_path()`, `shim_check()`, `fail_loud_on_dead_stream()`.

### `adapters/contacts.py` (FIX-02, route follows the probe)
**Analog for route (b), a host cap:** `mail_triage.py:59` and its call sites (292-294).
```python
_TRIAGE_TIMEOUT = 600.0
runtime.run_osascript(_INBOX_TRIAGE, str(NEEDS_SCAN), timeout=_TRIAGE_TIMEOUT)
```
Contacts today: `raw = runtime.run_osascript(_SEARCH, name, str(MAX_CONTACTS))` (line 176, default 30 s host cap against a `with timeout of 120 seconds` backstop). Add a module-level numeric constant `_SEARCH_TIMEOUT` and pass `timeout=_SEARCH_TIMEOUT`. GATE-10 resolves a bare module-level `Name` only. Raise the `with timeout of N seconds` in `_SEARCH` to at least the cap. Leave `_VERIFY` and `_CREATE` at 120.
**Route (a), a bulk read:** replace the `repeat with p in (people whose ...)` loop (lines 47-58), which re-evaluates the `whose` specifier on each property read. Use the measured form (`get people whose ...`, or one Apple event per property). Keep the US/RS framing and `_parse`. Correct the false comment at lines 35-37 ("one cheap Apple Events call"). The `docs/mail-applescript-facts.md` section 5b states that `whose` re-evaluates per iteration.
**Seam rule:** keep `from .. import runtime` and call `runtime.run_osascript(...)`. `tests/test_native_seam.py` forbids `from ..runtime import run_osascript`.

## Shared Patterns

### Qualified runtime import (Mail and Contacts files)
**Source:** `adapters/mail_addressing.py:315`, `adapters/contacts.py:176`, `adapters/mail_triage.py:292`.
**Apply to:** `contacts.py`, `mail.py`, `mail_addressing.py`. Call `runtime.run_osascript(...)` after `from .. import runtime`. `tests/test_native_seam.py` enforces this.

### Typed errors, agent-directed text
**Source:** `macos_apps_mcp/errors.py` (`NativeError` subclasses). **Apply to:** FIX-02 route (c): raise or classify with a message that names the real cause. Never return `[]` for a failure.

### Hermetic tests that fail closed
**Source:** `tests/conftest.py` (`_no_real_osascript`, `_reset_account_map_globals`). **Apply to:** every new unit test. A test that reaches `run_osascript` fails by design.

### CI constraints
- No edit to `pyproject.toml` or `uv.lock` in a code PR (`version.yml`).
- Run `uv run pytest`, then `MACOS_APPS_READ_ONLY=1 uv run pytest`, then `uv run ruff check .` and `uv run ruff format --check .`.
- Privacy-grep each SUMMARY: no titles, names, addresses, account names or UUIDs from the iMac.
