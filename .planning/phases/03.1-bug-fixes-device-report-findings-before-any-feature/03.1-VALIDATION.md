## Sampling Rate

- **After every task commit:** Run the task's quick command, then `uv run ruff check . && uv run ruff format --check .`
- **After every plan wave:** Run the full suite command in the plan's lane, plus `gh pr checks --watch --required`
- **Before `/gsd-verify-work`:** Full suite must be green, and the device checks of 03.1-07 (D-14) are recorded
- **Max feedback latency:** ~40 seconds (both pytest passes)
