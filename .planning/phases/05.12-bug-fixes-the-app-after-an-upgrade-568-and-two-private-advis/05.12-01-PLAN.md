  index 1) and samples for 5 s: `AXFrontmost` of Mail every 20 ms, the window index every
  250 ms. It prints the time of the first true (or `never`), the time of the first index 1,
  and the half that was false.
- `paste-cycle <message id> <account> <mailbox path> [--after <s>]` (M3): ONE process for
  one whole cycle, so no session turn sits between its steps. It opens a scratch reply;
  waits `--after` seconds with the same countdown; prints `trigger_age_ms`, `front_bundle`,
  `mail_cpu` and `mail_uptime_s`; snapshots the clipboard; writes the marker as a transient
  item; posts Cmd-V to Mail's pid; samples the body every 10 ms for at most 30 s; prints
  `settle_ms` (or `never`); discards the reply; restores the clipboard.
- `empty-paste <window id>` (M4): hash the body, empty the pasteboard, post Cmd-V, wait 2 s,
  hash the body again, restore the clipboard, print `body_equal` and `restored`.
- `stop-paste <window id> <outgoing id> --hand <outgoing id>` (M5): stop Mail for 3 s,
  write the marker, post Cmd-V during the stop, start the discard, continue Mail; print the
  time when the discard answered and whether the hand window's body changed.
- `sig-ax <window id> <outgoing id>` (M6): read the reply's signature text and the body
  through Accessibility, print `signature_read` and `in_ax_body` (yes or no), never text.
- `stored-diff --account <account id> [--budget <s>]` (M9): run the old and the new strip

  signature account; never a family or shared account), for at most the budget (default
  120 s). It prints the counts of files read, parsed, different and skipped as too large,
  `partial=yes|no`, and one count for each input class of the files that differ, so a
  `differ` above 0 can be acted on without reading mail.
- `hand-hash` and `stop-mail <seconds>`: helpers for M5 here and for M16 at sitting 2 (plan
  09). `hand-hash` prints the hash of the body of the compose window that holds `P0512HAND`
  and that window's outgoing id. `stop-mail` is a bounded stop of Mail that starts when a
  new Mail window appears.
