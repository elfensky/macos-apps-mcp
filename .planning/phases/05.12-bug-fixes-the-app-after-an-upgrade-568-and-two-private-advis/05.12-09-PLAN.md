- An app outside `/Applications/macos-apps-mcp.app` shows an alert and installs nothing.
- Agent status `requires-approval`: an alert that names Login Items.
- A first open (the agent is not enabled, or the setup marker exists): write the marker,
  register the agent, wait for the daemon's answer, run the consent pass
  (`doctor(request=True)` from the daemon), remove the marker, link the CLI, open Health.
- A later open: compare the daemon's identity with the app's own; restart once when it
  differs; wait for the answer with one alert; link the CLI; open the dashboard home.
