# Phase 05.12 Plan 06: The store lock and the script-guard ties

## Result

- A function-scoped autouse fixture moves each home-anchored store path to an absent temp path and moves the file root. An audit hook refuses a read, a write or a delete under a real store area before it happens, and fails a test that swallowed the refusal. A test with the `integration` marker is exempt.
- Tests that open a real store: 23 in 8 files before, 0 after. 21 needed no edit; 2 Notes tests got a fixture store. No test was removed, skipped or moved to `integration`.
- `_isolated_state` now moves `daemon._DEFAULT_SOCKET_DIR`: one test created that folder under the real home on each run.
- Two guards: each `osascript` call site is in the compile inventory, and each function that starts `osascript` is the door `runtime.run_osascript` or a pinned function with a hash of its source (`deploy._alert`, `deploy._wait_notice`, `deploy.dashboard`).
