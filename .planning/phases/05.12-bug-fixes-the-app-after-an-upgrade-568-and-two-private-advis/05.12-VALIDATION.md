file (`tests/mailhtml.py`, `tests/test_script_addressing.py`) runs it in its own task.

## Sampling Rate

- **After every task commit:** Run the `<automated>` commands of that task (each is a `-k` filter or a short file list), then the quick run command
- **After every plan wave:** Run the full suite command on develop's tip
- **Before `/gsd-verify-work`:** Full suite must be green, the store audit must read 0 rows (`PYTHONPATH=<05.12-proto> uv run pytest -q -p store_touch_audit`), and sitting 2 (plan 09) must be recorded
- **Max feedback latency:** 60 seconds
