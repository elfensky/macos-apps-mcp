Design that binds (research, "FIX-34" and "Code Examples"):
- `_BLOCK = re.compile(r"(?is)<(script|style).*?</\1>")` and `_TAG = re.compile(r"<[^>]+>")`
  are the old patterns, unchanged. `_OPENER = re.compile(r"(?i)<(script|style)")` is new.
- `_drop_tags(chunk)`: no tag ends after the last `>`. Cut the text there, run `_TAG.sub(" ", …)`
  on the first part, append the rest.
- `_drop_blocks(chunk)`: find each opener with `_OPENER.search`. Try `_BLOCK.match` at the
  opener. A failed try means that no closing tag for that captured name exists from there on.
  Remember the lower-cased name and skip later openers with it. A match removes the block and
  the search goes on after it.
- The prototype `05.12-proto/split_quote_linear.py` holds this code (`drop_blocks`,
  `drop_tags`), the old steps (`old_blocks`, `old_tags`), the generator (`reply_html`,
  `message`, `crafted`, `_TOKENS`) and the review form. The review form is NOT copied.
- Prototype run of 2026-11-20: 8,000 generated bodies and 200,000 crafted texts, 0 differences
  for the exact form. The 256 KB case: 0.008 s new, 28 s old.
