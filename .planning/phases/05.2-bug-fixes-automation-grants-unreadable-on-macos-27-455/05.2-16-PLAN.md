- Digest: for a text T, A = the characters of `unicodedata.normalize("NFC", T)` for which
  `str.isalnum()` is true (the letters-and-digits form `runtime._alnum` gives); it prints
  `len=<number of characters of A> sha256=<SHA-256 hex of A encoded UTF-8>`.
- `--selftest`: no Mail access, no file read, no file written. It digests the literal
  `"Jane Doe\nExample Corp \u2014 caf\u00e9 \u2713 42"`, then runs the `--eml` extraction
  on the in-memory HTML `<div>R2</div><div id="AppleMailSignature">Jane Doe<br>Example Corp
  \u2014 cafe\u0301 \u2713 42</div><blockquote type="cite">x</blockquote>` (decomposed é on
  purpose) and digests that; it also exits non-zero when the AppleScript constant
  `READ_SCRIPT` holds any of the whole words `make`, `delete`, `save`, `send`, `close`,
  `move`, `duplicate`. It prints exactly two lines:
  `selftest: len=24 sha256=6fe49cc6737de3c7ae836b2deb7b993c100b2afed3dea0194a935e60145af0bf` and `selftest-eml: len=24 sha256=6fe49cc6737de3c7ae836b2deb7b993c100b2afed3dea0194a935e60145af0bf`.
- `--eml <file>`: the text inside the element whose `id` is `AppleMailSignature` in the
  message's `text/html` part (`html.parser`, nested elements included; a void element —
  `br`, `img`, `hr`, `wbr`, `meta`, `input` — opens no nesting level, else the text after
  the block leaks in and the self-check fails); prints
  `eml: len=… sha256=…`, or `eml: none` when there is no such element.
- `--outgoing`: runs `READ_SCRIPT` once with `osascript`: for each outgoing message it only
  reads (`get`) its `message signature` and, when that is not `missing value`, the
  signature's `content`; prints one line per outgoing message, `outgoing <n>: missing` or
  `outgoing <n>: len=… sha256=…`. Run as the bundle with the `open -n` recipe.
- Every stdout line matches `^(selftest|selftest-eml|eml|outgoing [0-9]+): (missing|none|len=[0-9]+ sha256=[0-9a-f]{64})$`;
  it prints no text, subject, address or id, writes no file and changes nothing in Mail.
