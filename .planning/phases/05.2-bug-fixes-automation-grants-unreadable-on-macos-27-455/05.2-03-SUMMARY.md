## Behaviour off macOS

`import ctypes` is stdlib. `_ae_lib()` (the only code that opens CoreServices) runs lazily inside the call, so importing `runtime` or `doctor` loads no framework and `tests/test_off_macos.py` and `tests/test_tools_list_anywhere.py` stay green. Off macOS, `automation_permission` is not on the worker, so it goes to `run_native`, whose first line is `require_macos()`: it raises `UnsupportedPlatform` and never reaches ctypes. `doctor.diagnose` refuses earlier for the same reason.
