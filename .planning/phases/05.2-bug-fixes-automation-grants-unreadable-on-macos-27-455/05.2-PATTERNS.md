**Dispatch rule to copy** (last line of `run_osascript`, L306): define the work as an inner closure, then run it on or off the worker.

**Analog:** `_automation_surfaces` (L169-202). Today's three branches, to be changed only in the middle one:
```python

        name = app.lower()
        if not tiers.adapter_enabled(name):
            out.append(_surface(name, "automation", None, "adapter_off"))
```

## Shared Patterns

### Qualified native seam (applies to doctor, all adapters)
Call `runtime.<seam>(...)`, never import the name (#176; enforced by `tests/test_native_seam.py`). One monkeypatch point per test.

### Errors are reported, never swallowed
Typed `NativeError`/`WriteRefused`; `str(e)` is the agent-facing remediation. Doctor turns failures into `surfaces` entries; the tool layer's `@_guard()` turns the rest into `ToolError`.

### Dry-run and native calls
Unit tests mock at the adapter boundary and the conftest lock fails closed. A new seam must be added to the lock the same commit it lands.

### Mail writes
Read `docs/mail-applescript-facts.md` first. Verify by running with the watchdog on, and judge the stored or delivered message, not the return value. Autosave lands ~15 s late.
