# Phase 05.2 Plan 10: mail_reply keeps Mail's own quote Summary

mail_reply keeps Mail's own quote (route a, M2) - PR #527, Part of #348. Merged by rebase to develop; tip b57ecf7. #348 and #516 are OPEN. The lane is removed.

## Route

- gap-route: a
- gap-mechanism: M2
- gap-no-quote: gui-replace
- gap-cleanup: rollback-sweep
- §4e `Id-free discard`: works (so `_DISCARD_NEW_REPLY` exists)

Branch rows built: M2 (`compose_insert` borrows the pasteboard, posts one Cmd-V to Mail's pid, restores); gui-replace (`include_quote=False` calls the same flow with `replace_all=True`, `_REPLY` deleted from `mail_drafts`); id-free discard works; rollback-sweep. Rows not built: M1, set-content, id-free discard fails, rollback.

## What was built

- **Seams (`runtime.py`).** `accessibility_trusted()` binds only the plain trust read. `compose_insert(window_id, text, *, replace_all, quote_tail, rollback)` follows §4e `Insert`: pasteboard snapshot, window check with activation (Mail active and the reply at index 1), focus check (AXWebArea whose window is the bound id, waits up to 3 s), `changeCount` guard, write with TransientType and ConcealedType, one Cmd-V to Mail's pid, settle within 1 s, restore only while `changeCount` is still the seam's own write. Private loaders (`_ax_lib`, `_cg_lib`, `_clipboard`, `_mail_pid`, `_hold_window`, `_focused_body`, `_read_body`, `_post_cmd_key`) are what tests replace.
- **Flow (`mail_outgoing.py`).** `open_reply_with_text` runs in one `run_native` closure: Accessibility check, quote-tail read from the original, outgoing-id baseline, Drafts baseline, `_REPLY_OPEN` (B1, closeable new windows only), `compose_insert`. Any later failure applies the discard rule (`_DISCARD_OUTGOING` by id, else `_DISCARD_NEW_REPLY`), then the sweep, then raises `ComposeRefused`. "Nothing was created" is said only when the discard answered `dead` and the sweep left no copy.
- **Sweep (`mail_reply_cleanup.py`, `_SWEEP_DELETE`).** New Drafts rows since the call's baseline, `In-Reply-To` = the original, exactly one match, text before the quote empty (attribution line only) or starting with the call's own text; deleted with a `whose message id` query in the reply account's Drafts.
- **Tool surface.** `mail_reply` permission is `("Automation", "Accessibility")`; tool docstring, `MailAdapter.reply` docstring, README and CHANGELOG say what it does.

## Deviations from Plan

### §4e-wins (Rule 1), each with its §4e row

1. **[Rule 1 - Bug] AccessibilityDenied text names both panes.** Plan: "Privacy & Security → Accessibility". Built: `errors.ACCESSIBILITY_PANE` = "System Settings → Privacy & Security → Device Control and Data Access (called Accessibility before macOS 27)", and the text says nothing was created. No "restart" wording. §4e `Identity`.
2. **[Rule 1] Confirm compares whitespace-squashed.** Plan: per-line compare. Built: NFC plus whitespace squash (`text.squash_text`) on both sides, so the AX walk dropping empty lines still passes. Tests: decomposed é with CRLF, and a read-back without the blank line between two paragraphs. §4e `Confirm`.
3. **[Rule 1] Window binding counts only closeable new windows** (a tiled viewer adds a non-closeable 13-px divider); zero or several refuse, with the rollback in the same script. §4e `Window identity`.
4. **[Rule 1] Settle needs the body to start with the text AND to differ from the body read just before the key event.** An unsettled paste calls the flow's `rollback` before the clipboard restore, inside `compose_insert`. This adds the `rollback` keyword to the seam. §4e `Confirm`, `Pasteboard`.
5. **[Rule 1] Activation:** Mail active and the reply at index 1, else activate Mail and set the reply's index to 1, then check again. It lives in `compose_insert`, not in `_REPLY_OPEN` (the plan put it in the script). §4e `Activation`.
6. **[Rule 1] Focus** is an AXWebArea whose window (`_AXUIElementGetWindow`) is the bound id; the seam waits up to 3 s. The SPI is the only window-number route built (the probe's frame fallback needs CoreGraphics window lists and was not needed). §4e `Insert`.
7. **[Rule 1] Pasteboard order and guards** as §4e `Insert`: complete-snapshot rule (unreadable type refuses; 0 items with types refuses; 0 items and 0 types restores with clearContents), `changeCount` checked before the write and before the restore, bound 1 s.
8. **[Rule 1] Quote check uses the original's own tail, and the seam signature grew.** Plan: confirmation needs the text first and "Mail's quote after it" with a one-signature seam. Built: `quote_tail` (last 6 words of the original, squashed) is read through `_ORIGINAL` before anything is created; an unreadable original refuses with nothing created; an unknown tail refuses before any write. gui-replace has no quote check and requires that nothing follows the text. Plan test `reply_keeps_mails_quote_through_the_insert_seam` ("no `_ORIGINAL`") became "reads `_ORIGINAL` first". §4e `Confirm`.
9. **[Rule 1] Cleanup is rollback-sweep per the owner decision of 2026-11-01** (see above), with the sweep reading the Envelope Index and `.emlx` files, deleting by `whose message id` in the reply account's Drafts, never `delete_draft`'s unified walk (#521). §4e `Refusal cleanup`.

## Known limits (fail-safe, for 05.2-13 to watch)

- The AX walk stops after 400 nodes (`_AX_WALK_BUDGET`): on a much longer original the quote check can end before the tail and the call refuses. Raise the constant if a device run shows it.
- Window id comes only from `_AXUIElementGetWindow`; if that SPI were absent every call would refuse at the focus check.
- Sweep recognises Drafts mailboxes named `Drafts`/`Draft` and an English `On … wrote:` attribution line; anything else is reported as "may be left", never deleted.
- Every refusal after the window opened takes about 45 s (the owner's decision), including the open-failed case where the window time is unknown (the wait starts when the open returned or failed).
- The launchd daemon's Accessibility identity equals the bundle run of 05.2-09: assumed, checked in 05.2-13.
