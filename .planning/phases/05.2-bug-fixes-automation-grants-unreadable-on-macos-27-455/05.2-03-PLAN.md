<objective>
FIX-14, first part (#455): `doctor(request=False)` reads each Automation grant live,
without a prompt, through one native seam.

- `runtime.automation_permission(bundle_id)` wraps `AEDeterminePermissionToAutomateTarget`
  with `ctypes` on the single worker (O3); the conftest lock refuses it in unit tests.
- `doctor` maps the code to `granted`, `denied`, `not_asked`, `not_running` or
  `probe_error` (O6, O7) in the existing `surfaces` list, which 05.2-04 makes the Health
  page read (O2).

Purpose: one function answers for both `doctor` and the Health page, so they cannot
disagree, and macOS 27's missing AppleEvents rows no longer leave every grant unknown.
Output: one PR rebase-merged to `develop` (`Part of #455`).
</objective>
