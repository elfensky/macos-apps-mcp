# Preserve proxy discovery errors

## Objective and consensus

Issue #543 observation 1 is a migration follow-up under MIG-01.
The accepted GPT/Claude decision uses public `provider_error_strategy="raise"` in `daemon.build_shim()`.
One unavailable provider must produce a connection error, not a false `Unknown tool` or successful empty catalogue.
Healthy missing names retain `Unknown tool`. A later explicit request can recover without automatic replay.

**eli14:** The receptionist must report a disconnected phone instead of inventing an empty staff list.
Today, this prevents a misleading answer. Later, it prevents clients from treating a failed lookup as proof that tools disappeared.
