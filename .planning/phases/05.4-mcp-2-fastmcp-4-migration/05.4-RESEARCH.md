## Verified interfaces

- The local transport uses `httpx2.AsyncClient`, `httpx2.AsyncHTTPTransport(uds=...)` and `httpx2.Timeout(None, connect=10.0)`.
- `StreamableHttpTransport` still accepts `httpx_client_factory` with the same factory keywords.
- MCP 2 resolves abandoned SSE requests with `MCPError`, including exhausted reconnection attempts.
- The client identity path is `context.session.client_params.client_info`.
- `Implementation` discards unknown fields, including the former `session` extension and `_meta`.
- An explicit shim HTTP header survives the proxy transport. `get_http_headers()` exposes it at the daemon.
- `mcp.types` remains an import namespace. Model field names use snake case.
- `fastmcp.tools.tool` is removed. `fastmcp.tools.ToolResult` is the public replacement import.
- FastMCP raises the Starlette floor to 1.0.1. Dashboard behavior therefore belongs in migration verification.
- The new transport defaults to a 1 MiB SSE event limit. Large responses need explicit regression coverage.
- MCP still requires `pyjwt[crypto]`. The Intel cryptography policy remains applicable.

## Synthetic transport evidence

The probe used real UDS transport and synthetic tools. It accessed no native application data.

| Case | Observed result |
|---|---|
| Legacy client through proxy and UDS | Client name, version and shim header preserved |
| Modern client through proxy and UDS | Client name, version and shim header preserved |
| Six-second streamed call | Successful result with no read deadline |
| Interrupted legacy SSE response | Prompt `MCPError` without the old monkeypatch |
| Interrupted modern SSE response | Prompt `MCPError` without the old monkeypatch |

The interrupted-stream message was `SSE stream ended without a response`.
The current custom factory uses a modern backend for either frontend protocol era.
Public `context.session.protocol_version` and `Client(mode=...)` permit explicit era matching if required.
The probe emitted an upstream logging-capability deprecation warning.

## Recommended implementation boundary

Use the supported transport behavior and remove the private MCP 1 patch after equivalent regression tests pass.
Add the operation-outcome warning at an application-owned shim boundary. Preserve the original error code and never replay the request.
Carry shim identity in a sanitized HTTP header. Keep it advisory, with explicit fallbacks outside an HTTP request.
Test normal responses, interrupted responses, long calls, oversized responses, notifications and both frontend protocol eras.
Keep the native runtime, tool gates, audit semantics and notice policy unchanged.

**eli14:** The SDK is the cable between the client and the server.
The new cable reports a broken connection. That report still needs a warning that the server may have completed the command.
