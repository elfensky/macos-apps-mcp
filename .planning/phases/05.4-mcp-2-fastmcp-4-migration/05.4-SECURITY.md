# Cryptography compatibility exception

**Evidence date:** 2026-11-03
**Scope:** MCP 2.3.0, FastMCP 4.1.6, cryptography 48.0.1; local daemon without authentication.
**Decision:** Retain the existing Intel compatibility cap for the reviewed configuration. Keep dependency alerts open.

No reachable vulnerability was found in the reviewed AES-GCM/HKDF request-state path.
This assessment does not establish that cryptography 48.0.1 is safe for other uses.
The package is imported and bundled. Its compatibility exception depends on affected API reachability, rather than absence of imports.

## Runtime evidence

MCP's versioned `mcp/server/request_state.py` uses HKDF-SHA256 to derive a 32-byte key.
Its codec uses AES-GCM, random 12-byte nonces, authenticated metadata and `InvalidTag` rejection.
The application configures no MCP authentication. Its socket directory and socket are restricted to the owning account.

FastMCP imports X.509 code through `joserfc`. Certificate parsing for public-key extraction differs from the affected chain-verification operations.
Static inspection found no certificate-verifier or PKCS#7 decrypt calls outside cryptography in the reviewed application dependency paths.
HTTPX2 uses Python's standard `ssl` module; the shim itself uses HTTP over the local Unix socket.

The installed wheel embeds OpenSSL 4.0.1.
CVE-2026-75803 concerns ChaCha20-Poly1305 and AES-OCB through `EVP_Cipher()`, rather than the reviewed AES-GCM operation.
The cryptography AES-GCM implementation uses update/final processing.

## Compatibility and verification

Version 48.0.1 has universal2 wheels. Version 49 removed Intel macOS support; current 50.0.2 macOS wheels are ARM-only.
The current universal bundle requires matching file trees and Python sources before combining native binaries.
Different versions per architecture or a custom Intel security backport would require separate build and maintenance work.

Request-state encryption roundtrip and tamper rejection passed.
Empty and nonempty AES-GCM payloads rejected modified tags and authenticated metadata.
Twelve transport regressions passed with affected API exports replaced by raising guards.
Subprocesses did not inherit those guards. Static inspection supports their assessment; the test does not prove full subprocess coverage.

Reassess this exception before enabling authentication, certificate-chain verification or PKCS#7 processing, or changing the relevant dependencies.
Dependabot alerts remain open. This document does not authorize dismissing them.
