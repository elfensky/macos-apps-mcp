## Findings

- Mail saves an open draft again as a new index row about 30 s after `create_draft` opens it. The first row is then gone, and a scoped query on it counts 0 (one of five runs in the first set). The #521 lookup must expect a dead id for a draft with an open compose window.
- `Bulk` (the Junk folder name of one mail provider) is not in the special-folder table: a finding for #501.
- `delete_draft` deleted each of the three scratch drafts on the first call, with about 290 drafts in the unified mailbox and Mail idle. The timeout of #521 was not seen on an idle Mail.
- A format command by key event reaches Notes only while Notes is the active app.
- The probe needed no change. Two scratch helpers (the note typing and the compose-window close) stay in the git-ignored evidence folder.
