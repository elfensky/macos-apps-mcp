# #501 implementation working notes

This file preserves investigation history. It is not an end-state report.

- The initial sandboxed `uv sync` failed with `Could not acquire lock` and `Operation not permitted` in the uv cache.
  Authorized escalated execution installed the locked environment. No dependency versions changed.
- Apple resource strings differ from the prior-art list in several languages. The implementation retains prior names and adds current resource spellings.
  The static resources do not establish AppleScript runtime behavior. No device was probed.
- The first focused run reported `3 failed, 381 passed in 3.24s`.
  The three tests pinned English-only suffix lists and the broad Junk/Spam prefix. Their expectations now reflect explicit translated names.
- The next focused run reported `23 failed, 603 passed in 3.71s`.
  New tests used the nonexistent `query_headers` API, expected an exact empty result for a tokenized body query, and retained obsolete localized-Sent expectations.
  The tests now use `query_search`, a unique body-only search token and D-14's exact comparisons.
- A full run reported `1 failed, 3212 passed, 105 deselected, 7 warnings in 81.18s (0:01:21)`.
  The failing test was `test_localized_sent_twin_uses_exact_shared_vocabulary`.
  Actual output: `AssertionError: assert Draft(kind='unproven', url='', mid='') == Draft(kind='one', ... mid='<d@x>')`.
  The test fixture decoded only `%20`, `%5B` and `%5D`, so its synthetic non-ASCII mailbox directory did not match the URL.
  The fixture now uses standard URL decoding. The unchanged production cleanup then passes canonical Dutch, French and Russian cases.
- Benchmark lint initially reported `I001 Import block is un-sorted or un-formatted`; a missing import-group blank line was corrected.
- The expanded vocabulary alone increased synthetic search latency. Materializing only mailbox classification removed per-message name-list evaluation.
  Materializing logical membership itself was deliberately avoided because its recorded #299 regression remains relevant.
- The French Microsoft archive initially returned `jq: parse error: Invalid numeric literal at line 2, column 10`.
  The retry returned bookmark 4681. All cited references have archive pointers in the summary.
