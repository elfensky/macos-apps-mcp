# System folder classification

The implementation follows decisions D-10 through D-14 in [CONTEXT](05.6-CONTEXT.md).
The baseline is migration commit `dce3324195b33ad2afe02d150adc6db786f359e0`.
FastMCP 4.1.6, MCP 2.3.0 and httpx2 remain unchanged.

| Technical contract | eli14 |
| --- | --- |
| Notes SQLite excludes folder type 1 with a NULL-safe predicate. Missing columns select the AppleScript fallback. | A folder's type acts like a bin symbol. The label's language does not change that symbol. |
| AppleScript receives researched translated folder names through argv. The integration comparison receives the same names. | When the symbol is unavailable, a list of translated labels identifies the bin. Unlisted labels remain a limitation. |
| Mail classification normalizes names and encodes NFC/NFD SQL patterns. Addressing retains the original decoded text. | Reading the label does not rewrite the address on the envelope. |
| Classification cost belongs to mailbox rows. Synthetic query measurements cover the affected reads. | Read each cabinet label once, rather than once for every letter inside. |
