Question 1: the image rule

After a reply is sent, the tool must prove that a stored copy is the reply's own. One part of the proof: the quoted mail must end with the original's last words.

What happens today

1. The mail you reply to
…see you on Friday.
Kind regards, Anna

It ends with a picture.

2. The quote in the sent reply
…see you on Friday.
Kind regards, Anna
<logo.png>

Mail replaces the picture with a text marker. Mail writes it as a hidden element with the id cid:….

3. The check

Last words found: yes

Nothing after them: no ("logopng" follows)

Result: "not sure" (unproven). Nothing is deleted.

Question 2: the INBOX rule

New tonight: after a send, a mail in an INBOX with the same Message-ID as the proven Sent copy counts as "the delivered copy" and is set aside. That rule assumes an INBOX never holds a draft. Nobody tested that.

The two things that can sit in an INBOX with that Message-ID

A delivered mail
Received: from server-1…
Received: from server-2…
Message-ID: <abc>POST
MARK

Each mail server adds a Received: line. It is the postmark.

Set it aside. This is the reply that came back to you.

A leftover draft (unusual setup)
Message-ID: <abc>
(no Received: line)

Only possible when an account uses its INBOX as its Drafts mailbox, and Mail's autosave keeps the same Message-ID.

Today's rule sets it aside too, and the tool reports "no copy left" although one is left. It deletes nothing wrong.
